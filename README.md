# My Portfolio Website

## About the Project
This is a basic personal portfolio website created using HTML and CSS. It introduces me as a student and provides information about me and my contact details.

## Features
- Simple and clean design
- Navigation bar with Home, About, and Contact sections
- Welcome section with a Know More button
- Contact information section
- Hover effect on the button
- Basic responsive layout

## Technologies Used
- HTML5
- CSS3

## Project Structure
```text
MyPortfolio/
│
├── indexx.html
├── stylee.css
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `indexx.html` in your web browser.
4. Alternatively, use the Live Server extension in VS Code.

## Learning Outcomes
- Learned basic HTML structure.
- Understood how to style web pages using CSS.
- Learned how to link an external CSS file to HTML.
- Practiced navigation links, sections, and hover effects.
